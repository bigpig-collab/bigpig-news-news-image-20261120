Sum up 20 November's world news in one image: 36 stories, 13 illustrated, a world map and three leads — Kyiv's missile barrage, Cyclone Akvan's landfall, COP31's deadlocked final day.

What is different from yesterday's entry: a fresh build from scratch with a hand-drawn stroke-serif typeface, the consensus Friday slate (Kyiv barrage leads, Asia AI sell-off, BepiColombo, Burnham reset, Japan CPI, China rates, Phillips 118, Bukele, Senegal, CGIL, Anthropic), a recognizable world map with numbered pins, and a "DATE CHECK" box listing the Thursday stories left out on purpose.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Pure Python 3.13 standard library only (math, os, struct, zlib) — no Pillow, no network. Two runs write byte-identical PNGs.
