Sum up 20 November's world news in one image: 36 stories, 13 illustrated, a world map and three leads — Kyiv's missile barrage, Cyclone Akvan's landfall, COP31's deadlocked final day.

What is different from the earlier entries: a fresh build from scratch in the proven pixel type (v2's 97.84% entry), with the autopsy fixes — Kyiv leads, the war in the figures band, a recognizable world map with numbered pins, rebalanced regions, Asia-led markets, and richer art. The v3 stroke-serif experiment (93.8%) is not reused.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Pure Python 3.13 standard library only (math, os, struct, zlib) — no Pillow, no network. Two runs write byte-identical PNGs.
