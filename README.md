Sum up 20 November's world news in one image: 34 stories, 11 illustrated, a world map and three equal leads — a broadsheet front page of the day.

What is different from yesterday's entry: a fresh build from scratch with a pixel-type masthead, a "day in figures" band ($81B / 9-6 / 110 KM/H / 99), three new lead scenes (Iran 2027, Shenzhen trilateral, ICJ scales), eight new grid scenes, a numbered world map with a legend, and a "Saturday" footer line for what happens next.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Pure Python 3.13 standard library only (math, os, struct, zlib) — no Pillow, no network. Two runs write byte-identical PNGs.
